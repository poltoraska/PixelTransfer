Для повторной проверки содержимого (телефон должен быть подключён в режиме MTP, сессия PixelTransfer закрыта):

```sh
clang -I /opt/homebrew/include -L /opt/homebrew/lib -lmtp Tests/verify-phone-files.c -o /tmp/pixel_verify_files
mkdir -p /tmp/pixel_readback
/tmp/pixel_verify_files /tmp/pixel_readback
shasum -a 256 /tmp/pixel_readback/* TestFiles/*
```

При добавлении разрешения user-selected files инструмент AddEntitlement в Xcode 27.0 дважды завершил Xcode с assertion в IDESandboxItemModel. Настройки разрешений при этом сохранились; подпись собранного приложения проверена и содержит App Sandbox, USB и user-selected read-only.
